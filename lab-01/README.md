## Aim
To create a basic HTTP server using Node.js and an Express server with multiple GET routes.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Visual Studio Code

## How to Run

1. Install Node.js.
2. Open the project folder.
3. Run npm install.
4. Run node server.js.
5. Open http://localhost:3000.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | / | Welcome message |
| GET | /about | Student details |
| GET | /time | Current date and time |
| GET | /contact | 404 error |
